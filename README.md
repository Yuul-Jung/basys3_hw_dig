# Basys 3 하드웨어 매뉴얼

Digilent Basys 3 하드웨어를 설명하는 웹 참고 자료입니다. 기술 본문과 회로도·보드 사진을 보존하면서 목차와 가독성을 개선했습니다.

- `index.html`: 좌측 목차 및 클릭 확대를 제공하는 웹 매뉴얼
- `assets/figures/`: 보드 및 회로 기술 도판 38개
- `.nojekyll`: GitHub Pages 정적 게시 설정
- 전체 PDF 페이지 이미지와 원본 PDF 파일은 포함하지 않습니다.
- 이름·자격·편저 등 개인정보 표기를 제거했습니다.

GitHub Pages 주소: https://yuul-jung.github.io/basys3_hw_dig/

원자료: [Digilent Basys 3 Reference Manual](https://digilent.com/reference/programmable-logic/basys-3/reference-manual)

기술 도판과 원 자료에 대한 권리는 해당 권리자에게 있습니다.
