# Basys 3 하드웨어 매뉴얼

Digilent Basys 3 하드웨어 참조 매뉴얼의 웹 배포 프로젝트입니다.

- 원본 기술 설명과 보드 사진·회로 도판을 유지하고 읽기 편하게 구성
- 좌측 목차, 모바일 레이아웃, 본문 그림의 클릭 확대 기능
- 개인정보 및 PDF 원본 페이지 열람 요소 제외

## 게시 파일

- `index.html`: 매뉴얼 웹페이지
- `assets/figures/`: 본문 기술 도판 38개
- `.nojekyll`: GitHub Pages용 설정

**현재 상태:** 웹 매뉴얼 전체 파일 업로드 전입니다. HTML만 업로드하면 그림이 보이지 않으므로, 준비된 전체 배포 압축파일을 업로드해야 합니다.

원자료: [Digilent Basys 3 Reference Manual](https://digilent.com/reference/programmable-logic/basys-3/reference-manual)

기술 도판과 원 자료에 대한 권리는 해당 권리자에게 있습니다.
